# EWord 0.4.0 总体验收

本版为 Android 10+、ARM64 签名 APK，沿用现有应用标识和签名，正常覆盖安装保留原数据。旧 `EWord-universal.apk` 为 0.3.2 归档，不用于本轮验收。以下未勾选项是需要真机核验的步骤，不能理解为已经通过。

## 已有本机证据

- 原生引擎：45 项通过、1 项原有测试跳过，覆盖中文搜索、Word 编辑、签名、水印页码、扫描裁边、内容提取、转换和真正擦除。
- Microsoft Word 实际重开编辑后的中文 DOCX：两页、表格、原图片、页眉、页码域、正文日期和表格姓名保留。
- JVM 测试覆盖回收备份、版本上限、不完整备份、重命名迁移、最近锁定/排序、扫描草稿、页码范围、导出文件名与 MIME。完整检查的通过数量和原有测试问题见 RESULTS.md。
- APK 校验脚本检查模型实际字节、许可、ABI、网络权限、签名和对齐；不以这些检查替代手机推理。

## 安装与离线翻译（先验收）

- [ ] 覆盖安装后，旧最近记录、锁定、手动排序、存储的签名与扫描草稿仍在。
- [ ] 开启飞行模式并关闭 Wi-Fi；在 Word 正文或表格中长按选择中文 → 选区菜单“离线中英互译” → 中文转英文 → 翻译 → 核对原文与译文 → 复制译文到其他应用。
- [ ] 在具有文字层的 PDF 中选择英文，完成英文转中文。切换方向再翻译，原文件正文应保持不变。
- [ ] 测试数字、标点、换行、混合文本、短句、接近 2000 字选区；空选区/超过 2000 字应拒绝并说明原因。
- [ ] 首次本地资源准备、取消、返回、切换方向、后台再进入均无崩溃；记录首句与热态耗时和内存。
- [ ] 清除数据后的完全离线首启，需要独立测试包或没有个人数据的测试手机进行。**不要清除日常 EWord 的数据**，私有签名、草稿、版本和回收备份会一起清除。目前此项尚未执行。

## 阅读与 PDF 工具

- [ ] 打开双页中文样本，正文搜索有高亮，上一个/下一个循环正确；无匹配、扫描图片无文字层和搜索错误有明确提示。
- [ ] 更多 → 跳转到页码，检查首页、末页、0、超过总页数和非法输入。
- [ ] 缩放并滚动后切后台、关闭再打开，核对恢复页码、位置和缩放；阅读模式另测。
- [ ] PDF 工具箱 → 水印：分别选择中文文字与透明图片，改变透明度、大小、角度和位置，只应用 2 页或指定范围，预览并保存副本，在另一阅读器核对。
- [ ] 添加页码：起始 7、格式 `第 {page} 页 / 共 {total} 页`，分别检查页眉/页脚位置及指定范围；非法范围应拒绝。
- [ ] 图片批量转 PDF：一次选择 JPG/PNG，旋转、调整页序，生成后核对页数、顺序、方向及原图未改变。
- [ ] PDF 安全擦除：框选文字、图像并可选关键词，确认后导出副本。在其他阅读器复制/搜索，并用提取工具核对指定内容无法恢复。原文件与旧版本仍可能保留敏感信息，应用确认框已提示。

## 文件管理与恢复

- [ ] 首页右上角菜单 → 文件管理：搜索名称；选择 PDF/Word/图片等分类；逐一切换名称、类型、修改日期、大小的升降序及时间/大小筛选。
- [ ] 重命名 DOCX/PDF/PNG，后缀、阅读位置、锁定、顺序、关联版本/草稿应保留；同名失败不得覆盖文件。
- [ ] 创建副本及选择目录复制后，用其他应用打开，文件类型保持；移动成功后目标可读，源位置的备份可在回收站恢复。
- [ ] 对聊天只读附件取消移动或尝试无删除权限的移动，应保留原文件，并说明只完成了复制。
- [ ] 最近使用长按保持拖动；松手进入多选，底部有排列、删除、置顶、锁定、转发；短列表和长列表均可拖出有阻尼的边界空白。
- [ ] 删除默认只移除记录；勾选同时删除本地文件需二次确认。锁定项不能移除或删除，先解锁才可操作。
- [ ] 实际删除后到回收站恢复，下载目录生成不覆盖同名文件的副本；彻底删除有确认且不可撤销。
- [ ] 修改文档，稍作停顿，查看历史版本；恢复产生独立副本，当前原件保留。检查最新草稿和旧检查点内容区别。
- [ ] 在测试文档编辑正文/画线后停顿至少 2 秒，强制停止应用再打开，检查草稿恢复。不要用未备份的个人文件做强制终止测试。

## 扫描、签名、提取与转换

- [ ] 扫描开启连续拍摄，拍多页；逐页自动找边，手动修角、旋转、重拍、删除和调整页序；生成 PDF 并在外部核对。无法可靠识别边缘时应允许手动裁边。
- [ ] 相机返回取消、后台终止再进入，扫描页、裁边、方向与顺序应恢复；超过 50 页/80 MB 有提示。
- [ ] 拍照签名 → 裁剪页有确认 → 得到透明底黑色笔迹 → 在 PDF 和 Word 中放置、移动、缩放 → 另存并外部重开；保存的签名下次可复用。
- [ ] Word/PDF 更多 → 内容提取：分别输出 TXT、原图片 ZIP、HTML 结构；PDF 另测 XLSX 表格内容。检查范围、图像和实际文件后缀，原文不变。
- [ ] 转换前后切换预览，逐页查看；保存后在外部重开。PDF→DOCX 表格可能成为定位文字，界面已提示，不保证仍是可编辑表格。
- [ ] 断网复测原有 DOCX 编辑、PDF 批注、图片裁剪标记、OCR、Excel 切表、PPT 翻页、另存和系统分享。

## 外观设置（最后验收）

- [ ] 首页右上角菜单 → 设置 → 个性化 → 相册上传，选择大图/横图/竖图，返回首页及重启后保持；取消选择时背景不变。
- [ ] 恢复首页默认背景，最近文件与蓝紫玻璃按钮可读，按钮按压与拖动仍正常。
