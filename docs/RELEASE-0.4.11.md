# EWord 0.4.11：签名库与签名操作框

本版完善手写签名的保存、管理和放置方式，适用于 PDF 与 Word DOCX。Android 10+ / ARM64，可覆盖安装，保留已有应用数据。

## 1. 多份签名与长按删除

在文档的签名功能中点击“使用已保存签名”，即可浏览保存过的签名。点击缩略图使用；长按任意签名进入删除模式，各签名右上角显示红色叉号，点叉删除该份素材，点“完成”结束管理。长按触感遵循应用的触感设置。

新增签名改为逐份存储，不再覆盖上一份。旧版留在 `signature.png` 和 `initials.png` 中的现存素材继续可用，手写签名与缩写分别管理。旧版已经覆盖或未保存的签名无法从本次更新中恢复。删除库中素材不会擦除已经嵌入文档的签名。

## 2. 放置框：移动、缩放、拉伸与旋转

布局参考 [Word 的缩放手柄](https://support.microsoft.com/en-us/word/change-the-size-of-a-picture-shape-text-box-or-wordart-in-word) 与 [上方旋转手柄](https://support.microsoft.com/en-us/word/rotate-or-flip-a-text-box-shape-wordart-or-picture-in-word)，本应用按需求默认将四角设为等比缩放。选好签名后，在确认插入前可以：

- 拖动主体移动位置。
- 拖动四个角，按当前比例缩放，保持对角锚点。
- 拖动左、右侧手柄，只改变宽度；拖动上、下侧手柄，只改变高度。
- 拖动框上方延伸出的旋转手柄，自由调整角度。旋转后的手柄跟随签名方向。
- 取消拖动时恢复该次操作前的预览；拖动期间不能误点确认插入。签名保持在页面边界内。

## 3. 保存效果与资源控制

点击“确认签名”时，将预览中的拉伸、旋转绘制成透明 PNG，嵌入 PDF 或 DOCX。图像位置使用旋转后的外接矩形，原文档仍沿用现有的保存、副本与版本流程。Word 中尚未提交的正文修改会先提交，再插入签名。

库中的原始素材不随文档内的变换而改变。列表缩略图按需加载并缩小到 256 像素以内，放置预览解码限制在 2048 像素以内；导出图像最长边限制为 4096 像素，像素预算约 800 万，避免大照片无限放大占用内存。此处管理的是手写签名素材，数字证书签名继续使用原有流程。

## 验证结果与范围

- Android JVM 针对性测试：28 项通过。其中新增 4 项签名库测试，涵盖旧文件兼容、多份保存、重开、单份删除、失败写入、目录隔离；新增 5 项几何测试，涵盖四角比例、旋转后的固定锚点、侧边单轴拉伸、角度连续性、页面约束。
- 现有最近文件、设置开关手势、Office 原位输入和表格冻结区域定位测试继续通过。仍沿用本地排除既有 `ReadAloudLanguageTest` 编译问题的测试脚本，不宣称 Android 全量测试通过。
- 已新增可运行的独立设备检查：使用合成透明图验证拉伸、90°/45° 旋转方向及 PNG 透明度，随后写入 PDF、DOCX 并重开检查图像位置和嵌入内容。该检查只使用 `cn.jiandoc.app.debug` 调试包和合成样本，不读取正式版签名或文档，不执行触屏操作。
- Rust mobile 回归测试：51 项通过、1 项忽略。新增透明旋转参考图的 Word/PDF 保存重开验证，核对笔迹位置及透明缺口与原页面的像素一致性。
- Android 真机独立检查通过：3 项实际位图旋转/拉伸/透明度检查、1 项 PDF 保存重开检查、1 项 Word 保存重开及嵌入图检查，返回 SIGNATURE_CHECKS_OK。本次临时安装的调试包已卸载，未操作或清除正式版数据。实际手柄触控、长按管理、相机素材效果和系统另存仍需用户验收。

设备检查复现：准备 JDK、Android SDK、Rust 工具链和 ARM64 手机，先构建独立调试包与测试包，再运行检查脚本。

```powershell
cd upstream/android
./gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest
cd ../..
pwsh ./verification/verify-signatures-device.ps1 -AndroidSdk $env:ANDROID_HOME
```

脚本不会清除正式版数据；仅卸载本次临时新装的测试包，已经存在的调试包会保留。
