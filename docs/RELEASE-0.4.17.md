# 0.4.17 文件多选、讲义目录与首次缓存衔接

## 本次变化

- 首页蓝色文件按钮打开选择菜单，可选择多个文件、添加文件夹或浏览已添加的讲义文件夹。系统选择器内支持多选；多份文件统一加入“最近使用”，单份文件直接打开。只记录用户授权的本地文件引用，不向服务器上传，也不同时启动多个阅读器。无法读取的数量会单独提示。
- 新增讲义文件夹页面，保留课程目录层级，文件夹优先、名称排序，逐层读取当前目录。子目录不受原有平铺扫描的八层限制。目录读取失败提供重试；保留系统授予的文件夹权限，支持以后再次浏览。从首页更多菜单也可进入“讲义文件夹”。
- 针对首次兼容阅读缓存完成后停在首页的问题，将待打开请求放入 Android 保存状态；主界面进程重建后仍能找回来源与缓存位置，并等待文档引擎就绪后打开。提交完毕的缓存可用于恢复未及时送达的原生 Activity 返回结果；主动按返回取消会与异常退出区分。缓存无效时显示重试提示，不再静默回到首页。

## 构建与校验

Release 构建与 35 项相关 JVM 测试通过（阅读格式识别、缓存、最近记录、路径、覆盖恢复和阅读布局）；APK 签名、16 KB 对齐、Office 引擎、翻译模型和许可资产校验通过，仍无 INTERNET 权限。

本次发布包含 0.4.16 的[阅读缓存和界面优化](RELEASE-0.4.16.md)。已有版本可直接覆盖安装，保留应用数据。
