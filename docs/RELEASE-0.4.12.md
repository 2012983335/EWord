# EWord 0.4.12：拍照签名橡皮擦

## 更新内容

- 拍照或从相册导入签名，完成裁剪、自动抠图后，可开启“橡皮擦”清理多余笔迹，支持调节橡皮大小。点击可擦除一个点，拖动可连续擦除。
- 擦除直接清除 PNG 的透明通道，不使用白色涂层。原始导入图保持不变；完成后将清理结果交给原有签名库、旋转拉伸和 Word/PDF 插入流程。
- 每次擦除手势可单独撤销、重做；清空也可撤销。撤销后进行新的擦除，会替换原来的重做分支。全部擦空时提示恢复或重新导入，不会保存空白签名。
- 签名照片的初始裁剪框改为上下左右各内缩 10%，方便拖动四角和边线；使用现有 [Android Image Cropper 4.7.0 的内边距参数](https://github.com/CanHub/Android-Image-Cropper/blob/4.7.0/cropper/src/main/kotlin/com/canhub/cropper/CropImageOptions.kt)，没有新增裁剪依赖。

## 使用方法

拍照签名 / 从相册导入 → 拖动裁剪框，确认签名 → 点击“橡皮擦”，调整大小后涂抹多余部分 → 撤销或重做检查 → 完成 → 在文档中移动、旋转或拉伸 → 确认签名并保存文档。

橡皮擦属于拍照/图片签名处理页面。手写签名画板及文档内的 PDF 擦除工具继续沿用原有流程。

## 实现与核验范围

- 复用现有 Kotlin / Compose、图片裁剪库与签名保存流程，未引入新依赖。
- 历史仅保存擦除轨迹，不为每个步骤复制整张位图；确认时在后台生成透明结果。原有导入图片最长边 1200 像素限制保持不变。
- 31 项 Android JVM 针对性测试通过，包含新增 3 项擦除历史测试：撤销/重做边界、重做分支替换、清空恢复及轨迹隔离。现有签名库、旋转缩放、最近文件、设置开关手势、Office 原位输入与表格定位测试继续通过。沿用本地排除既有 ReadAloudLanguageTest 编译问题的脚本，不宣称 Android 全量测试通过。
- Android 真机独立检查通过：擦除透明度、未擦区域和原图保护、撤销、重做、全部擦空检查、单点擦除，连同位图旋转/拉伸和清理后 PNG 写入 PDF、Word 的保存重开检查，返回 SIGNATURE_CHECKS_OK。使用合成素材与独立调试包，无触屏自动化，未操作正式版界面或清除正式版数据，临时测试包已移除。
- Release 构建、原证书签名、16 KiB ZIP 对齐、7 项离线翻译模型大小和哈希、无 INTERNET 权限检查通过。
- 实际触屏涂抹手感、拍照抠图质量与四边裁剪拖动效果仍需用户验收；自动测试不代替这些操作的体验检查。
