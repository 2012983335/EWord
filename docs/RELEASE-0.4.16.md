# 0.4.16 阅读性能优化

旧版 PPT / ODP 的兼容阅读改为：内置 Office 引擎首次离线导出完整 PDF 阅读缓存，再交给 EWord 原有阅读器显示。保留文字、图片、公式和分页，避免在每次滑动和缩放时通过 Office WebView 请求页面分块。原有 DOCX、XLSX、PPTX 编辑入口保持不变。

原有阅读器提供邻页预加载、整页底图及缩放细节分块缓存，沿用 EWord 工具栏。首次生成缓存仍需要等待；再次打开内容相同的文件复用缓存，源文件内容变化后重新生成。缓存被系统清理后也会重新处理。

缓存按源文件 SHA-256 区分；中间导出文件经过 PDF 头尾检查后原子提交。阅读和批注使用独立工作副本，保存不能直接覆盖原始 PPT。阅读位置和“详细信息”的来源仍对应原讲义；另存阅读副本的格式为 PDF。

兼容引擎保留独立进程以隔离 native 生命周期，但不再创建第二个任务卡片。返回时立即结束阅读 Activity，原生引擎后台释放。
