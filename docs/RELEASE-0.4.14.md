# EWord 0.4.14：完整离线 Office 兼容阅读

旧版 PPT 出现有页数却大面积空白：原组件只提取文字大纲，既漏读内部文本框，也不渲染旧格式图片和公式。本版内置 Collabora Office / LibreOffice 阅读引擎，通过原始文件的只读副本浏览图文。

## 更新内容

- PPT/PPS/POT 根据扩展名和二进制头自动进入兼容阅读，显示旧课件的图片、公式、颜色、图形和排版；改名为 PPT 的 PDF 继续使用 PDF 阅读器。
- 新增 ODP、OTP、FODP 分类、系统打开入口和兼容阅读路径。
- Office 更多菜单新增“兼容阅读（已保存版本）”。Word、PPTX、XLSX 保留原编辑流程；兼容阅读显示已保存的磁盘版本，未保存修改请先保存。直接保存、另存为、详细信息仍列前三项。
- 阅读引擎运行于独立进程和独立任务，使用单文件授权及只读副本，不请求所有文件访问权限。原有 PDF、签名、扫描、翻译路径保留。
- 保留旧组件的文本框漏读修复、解析预算和中文提示。

## 离线与许可

引擎、前端和翻译模型随 APK 打包，首次使用会在本地解包部分资源，无需联网下载。最终 APK 无 INTERNET 权限。

上游源码固定为 `31fe13e27b4e317249fe6229a172fdbf2c2106d9`，官方 ARM64 构建 26.04.7.0-979。包装层及修改位于 `upstream/android/officecompat`。完整源码和许可见 [第三方说明](THIRD_PARTY.md)。开发时先运行 `pwsh ./verification/prepare-office-runtime.ps1` 准备经过 SHA-256 校验的资源；缺失时构建明确失败。

## 验证结果

- 两份用户原课件在真机上得到人工确认：图片、公式、排版基本正常；接入 EWord 后，第二份课件显示和返回均正常。原课件和手机截图不纳入仓库。
- 优化/混淆后的 fast 测试包实际打开课件，封面、正文、图形、公式可见。
- FODP 合成讲义的中文、英文、图形已实际显示；ODP 合成样本走通兼容阅读入口。复杂 ODP/OTP 样本仍需扩充。
- 34 项 Android JVM 针对性测试通过，覆盖路由、编辑路径、签名、文件管理手势和原位编辑。仍排除既有 ReadAloudLanguageTest 编译问题，不宣称 Android 全量测试通过。
- 独立调试包中，签名擦除、透明度、Word/PDF 保存重开、中英双向离线翻译检查通过，验证共用 C++ 运行库后两类原生引擎均可运行。
- 正式构建、原证书签名、16 KiB ZIP 对齐、七项翻译模型、Office 运行库、源码版本、许可及无 INTERNET 权限检查通过。
- 本次未额外切换飞行模式或清除正式版数据，未在 Android 10 真机或所有设备上测试。

## 资源与限制

APK 464,841,678 字节，约 465 MB；ARM64 / Android 10+。一次观察兼容阅读进程 PSS 约 424 MiB，不包括其他进程，实际随文件、设备与缓存变化。

兼容阅读使用自己的界面和状态管理，尚未与原阅读器的阅读位置、签名和批注工具栏互通。复杂文件需要样本验证，不保证所有字体、嵌入对象、视频、动画与原软件一致。EPUB、DjVu、CAJ 等仍是后续候选，未宣称支持所有讲义。见 [兼容性清单](LECTURE-COMPATIBILITY.md)。
