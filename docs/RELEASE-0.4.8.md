# EWord 0.4.8：基础表格与幻灯片编辑

0.4.8 本地开发记录，基于 0.4.7。相关能力已并入公开发布的 0.4.9；0.4.8 未单独发布到 GitHub。

## 使用

- XLSX：单击选择单元格后点“编辑”，或双击单元格。支持文字、数字和以 `=` 开头的公式；清空输入可清空单元格。可撤销、重做、切换工作表，点击“另存为”导出副本。
- PPTX：在底栏点击编辑，或更多菜单 → 编辑当前页文字。选择现有文字片段，修改后点“应用修改”，关闭文字列表检查页面，再通过“另存为”导出副本。文字片段保留其已有格式；长文字可能超出原文本框。
- 应用修改后保存到私有工作副本，复用现有草稿、版本和保存失败提示；不自动覆盖来源文件。退出时如未导出，仍提供保存副本的提示。

## 范围

PPT 编辑只修改原 OOXML 包内的文字节点，其余部件直接复制。没有新增幻灯片、图片、形状或完整排版编辑。旧版二进制 PPT 仍只读；现代 PowerPoint 文件的文字编辑限制在 64 MiB 以内，含数字签名的包拒绝修改。

XLSX 使用已有 GridCraft 修改、公式重算、撤销及保存接口；PPT 继续使用 DeckCraft 渲染，ZIP/XML 修改复用现有依赖 zip 3.0.0 和 roxmltree 0.20.0，没有引入大型办公套件。对应许可随 APK 打包。

## 核验

- Rust mobile 全套测试：48 项通过，1 项忽略。
- 新增 PPT 测试：文字修改、特殊符号、清空后重新填写、无效页码/片段/控制字符、渲染与搜索缓存、保存重开；比较所有 ZIP 部件，除了目标页 XML，其余解压内容逐项相同。另测带数字签名标记的包拒绝编辑。
- 新增 XLSX 测试：中文、多工作表、数字、公式、计算结果及未编辑区域在保存重开后保留。原有重算、撤销、格式修改与保存测试通过。
- 桌面 PowerPoint 实际重开两页 PPTX，修改文字及特殊符号正确；Excel 重开 XLSX，公式 `=SUM(B2:B3)` 可读，计算结果 14。
- Android 首次 Release 构建通过，最近文件与开关手势的 13 项针对性测试通过。测试编译沿用本地排除既有 ReadAloudLanguageTest 问题的脚本，不代表 Android 全量单元测试通过。
- 手机上的编辑手感、软键盘、系统另存与其他手机办公软件重开仍需手工验收，未以引擎或桌面检查代替手机验收。
